🌱 皮克敏抽直屬活動系統

使用說明

本系統對應企畫書中的「召集任務」環節：主持端負責出題並顯示題目與名額進度， 報到處的工作人員在確認新生的皮克敏身分卡符合條件後，點選對應的按鍵回報， 該按鍵會立即變灰、並同步顯示在主持端畫面上。

兩端請分別在不同裝置（例如主持端用連接投影機的筆電、報到端用平板或手機）開啟對應的頁面。

🎤

主持端

設定並發布召集任務、顯示本輪進度與歷史紀錄

 📋

報到回報端

報到處人員專用，一鍵回報符合條件的皮克敏卡片

設定提醒

目前若尚未設定 Firebase，系統會自動使用「本機測試模式」，只能在同一台電腦的不同分頁間同步， 方便先測試操作流程。正式活動當天要讓不同裝置互通，請先依照 README 設定 js/firebase-config.js。
