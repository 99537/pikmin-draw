🌱 皮克敏抽直屬活動系統

使用說明

本系統對應企畫書中的「召集任務」環節。報到處人員在新生報到時先用報到端登記每張 皮克敏身分卡，這些登記會自動成為卡池；主持端只要按「自動產生任務」，就能從卡池裡 挑出保證解得出來的召集題目並發布。之後報到處人員再依任務條件點選對應按鍵回報， 進度會即時同步顯示在主持端畫面上。

兩端請分別在不同裝置（例如主持端用連接投影機的筆電、報到端用平板或手機）開啟對應的頁面。

設定提醒

目前若尚未設定 Firebase，系統會自動使用「本機測試模式」，只能在同一台電腦的不同分頁間同步， 方便先測試操作流程。正式活動當天要讓不同裝置互通，請先依照 README 設定 js/firebase-config.js。
